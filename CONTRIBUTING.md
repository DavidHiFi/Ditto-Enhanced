# Contributing to Ditto-Enhanced

Thanks for helping. Bug reports, ideas and pull requests are welcome.

## Reporting a bug

Open an issue at https://github.com/DavidHiFi/Ditto-Enhanced/issues/new and include:

- what you did, what you expected and what happened instead
- your Windows version and the Ditto-Enhanced version
- a screenshot or the log file

## Sending a pull request

1. Fork the repo and create a branch from `master`.
2. Build with VS 2022: `msbuild CP_Main_10.sln /p:Configuration=Release /p:Platform=x64 /p:PlatformToolset=v143`.
3. Keep each pull request to one change, and say how you tested it.
